# Industry professional logo assets

Six carousel-ready SVG marks are stored in this directory. They use a transparent background and BFN ink (`#0b0f14`); white negative-space details are preserved where the source mark has them.

| Asset | Source |
| --- | --- |
| `wells-fargo.svg` | [Wells Fargo - official site header mark](https://www.wellsfargo.com/) |
| `goldman-sachs.svg` | [Wikimedia Commons - Goldman Sachs 2022 Black](https://commons.wikimedia.org/wiki/File:Goldman_Sachs_2022_Black.svg) |
| `credit-agricole.svg` | [Wikimedia Commons - Crédit Agricole 2017 logo](https://commons.wikimedia.org/wiki/File:Cr%C3%A9dit_Agricole_logo_2017.svg) |
| `principal-financial-group.svg` | [Wikimedia Commons - Principal Financial Group logo](https://commons.wikimedia.org/wiki/File:Principal_Financial_Group_logo.svg) |
| `wall-street-oasis.svg` | [Wall Street Oasis - official site header mark](https://www.wallstreetoasis.com/) |
| `streetsmart-careers.svg` | [StreetSmart Careers - official site header mark](https://streetsmartcareers.com/) |

The original downloaded files remain under `source/` for provenance. Site-sourced PNGs are rendered through local SVG wrappers and recolored in-browser; the other marks are vector paths recolored directly.

These are trademarked brand marks. Confirm each organization’s usage/endorsement requirements before publishing the carousel.
